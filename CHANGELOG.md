# Changelog

All notable changes to this project will be documented in this file.

The format is based on Keep a Changelog, and this project adheres to Semantic Versioning.

---

## [1.0.1] - 2026-07-31

### Added

- Student result lookup and terminal result display.
- Add and update marks for existing students.
- Removal of student records and individual subjects.
- View-all option for browsing saved records.
- Average calculation and basic result statistics.
- Help menu with in-app instructions.
- JSON-based persistence across application runs.

### Changed

- Reorganized the project into a modular architecture with dedicated feature, UI, utility, and database modules.
- Improved CLI prompts, formatting, and user feedback.
- Enhanced the terminal interface with reusable banners and colorized output.
- Updated project documentation and usage instructions.

### Fixed

- Improved validation for student names, subjects, and marks.
- Fixed formatting inconsistencies in prompts and result displays.
- Corrected statistics rendering and result box formatting.

---

## [1.0.0] - 2026-06-19

### Added

- Initial CLI-based Mark Registry App.
- Basic project structure and entry point.
- Early documentation and repository setup.
